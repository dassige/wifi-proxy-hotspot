Wi-Fi Proxy Hotspot Administration

This gateway sits between devices on its Wi-Fi network and the internet. By default, every device that connects to the Wi-Fi access point below has its traffic {{ 'sent direct, bypassing the proxy' if default_action == 'direct' else ('routed through the "' ~ default_action ~ '" proxy profile') }}, except devices on the internal network ({{ bypass_cidr }}), which are always reached directly, and any domain matched by a routing rule, which overrides the default for just that domain. Use the menu to change the upstream proxy, the Wi-Fi network devices connect to, the default behaviour and its pattern-rule overrides, and to see which devices are currently connected.
