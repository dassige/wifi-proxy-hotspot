Proxied Lookups {{ help_btn('help-resolve-via-proxy') }}

{{ help_dialog('help-resolve-via-proxy', HELP_RESOLVE_VIA_PROXY) }}
Look up hostnames matched by a proxied rule through that proxy

Makes video CDNs hand out servers near the proxy instead of near this box, so a proxied stream doesn't cross the long link to the proxy twice. Falls back to ordinary DNS whenever the proxy isn't ready. Only hostnames matched by a rule are affected, not the default.
